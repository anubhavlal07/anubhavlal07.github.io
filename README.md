## Project Structure

The project is organized as follows:

```

├── assets/
│   ├── css/
│   │   ├── styles.css           # Main stylesheet
│   │   └── swiper-bundle.min.css # Swiper JS stylesheet
│   ├── img/                     # Images and assets (Profile pics, shapes, etc.)
│   ├── js/
│   │   ├── disableInput.js      # Utility for disabling input
│   │   ├── loadExperience.js    # Dynamically loads experience data
│   │   ├── loadProfile.js       # Dynamically loads profile data
│   │   ├── loadProjects.js      # Dynamically loads projects data
│   │   ├── loadSkills.js        # Dynamically loads skills data
│   │   ├── main.js              # Main application logic (Menu, Theme, etc.)
│   │   ├── quotes.js            # Quote generator logic
│   │   ├── resumeModal.js       # Modal logic for resume
│   │   ├── scrollreveal.min.js  # ScrollReveal library
│   │   └── swiper-bundle.min.js # Swiper library
│   └── json/
│       ├── experience.json      # Data for experience section
│       ├── profile.json         # Data for profile section
│       ├── projects.json        # Data for projects section
│       ├── resume.json          # Data for resume modal
│       └── skills.json          # Data for skills section
├── index.html                   # Main entry point
└── README.md                    # Project documentation
```

## Features

-   **Responsive Design**: Fully responsive layout using CSS Media Queries for Mobile, Tablet, and Desktop.
-   **Dynamic Content**: Content (Experience, Projects, Skills) is loaded dynamically from JSON files (`assets/json/`), making updates easy without modifying HTML.
-   **Interactive UI**:
    -   **Swiper.js** for touch-friendly project carousels.
    -   **ScrollReveal.js** for smooth scroll animations.
    -   **Dark/Light Theme**: Toggle button to switch between themes.
    -   **Resume Modal**: Pop-up modal to view resume details.

## Technologies Used

-   **HTML5**: Semantic markup.
-   **CSS3**: Custom properties (variables), Flexbox, CSS Grid.
-   **JavaScript**: ES6+ features, Fetch API for JSON data.
-   **Swiper.js**: Modern touch slider.
-   **ScrollReveal.js**: Scroll animation library.
-   **RemixIcons**: Open-source neutral-style icon system.
